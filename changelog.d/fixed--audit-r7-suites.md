- **Test suites no longer go red with the calendar** (audit R7 M-1). Ten server tests and nine client tests carried literal dates that the clock was about to pass (the first on 2026-11-07, the finance ones every New Year); their dates are now relative to today, or the clock is pinned where the test is about a calendar year.
- **The E2E servers reach no external service** (audit R7 L-1, spec `e2e-playwright-smoke-suite.md` rule 23). `GUESTFLOW_DISABLE_OUTBOUND=1`, set by every Playwright server, skips the GitHub release check (`self-update-and-releases.md` rule 51) and the school-holidays sync (`school-holidays.md` rule 27, plugin 1.0.4), so a run no longer depends on GitHub or `data.education.gouv.fr`.
- **A hanging server test fails instead of stalling CI** (audit R7 L-2, `server-test-isolation.md` rule 5). The server and control-plane suites run with `--test-timeout`, so a test that never settles fails and its file is named, instead of the job being cancelled at its 15-minute limit.
