- **No more reload loop on a missing page file** (spec `inte-performance.md`, 2026-10-28). A page file answered by the SPA fallback reloaded the app in a loop because a successful prefetch of another page cleared the guard; the guard is now per route and cleared only when that route renders. Also: price calculations and previews no longer make the side menu re-read the properties, a read started after a write settles never joins one started before it committed, the client search of an existing stay loads its list when the client lookup fails, « Réessayer » in the email editor keeps what was typed, and the release archive no longer carries the Vite manifest.
