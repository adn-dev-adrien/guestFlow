- Installing a release (self-update and fleet console) now runs `npm ci --ignore-scripts` with a minimal environment and rebuilds only the native modules explicitly, so a release's install scripts can no longer read the installer's secrets. Releases can additionally be required to carry an Ed25519 `SHA256SUMS.sig` once `GUESTFLOW_RELEASE_PUBLIC_KEY` is set (`scripts/sign-release.mjs`).
