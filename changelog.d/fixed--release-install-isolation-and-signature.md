- Installing a release (self-update and fleet console) now refuses a lockfile that resolves anything outside the npm registry or without an integrity hash, then runs `npm ci --ignore-scripts` with a minimal environment (proxy settings kept, persistent npm cache), so no install-time code of a release or dependency runs. The install still runs as the installer's own unix user (see self-update rule 39). Releases can additionally be required to carry an Ed25519 `SHA256SUMS.sig` once `GUESTFLOW_RELEASE_PUBLIC_KEY` is set (`scripts/sign-release.mjs`, step 8b of the release skill).
