- `property_resource_prices.price` accepts NULL (`resource_property_price_nullable_v1`, `specs/options-resources-ux.md` rule 28): a resource's property line with only a free first hour now inherits the base price instead of storing a copy of it. The table is rebuilt at boot with every row and value kept as stored; existing rows are not reinterpreted (a stored `0 € + 1 h offerte` line stays « free there »).
