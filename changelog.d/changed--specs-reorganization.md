- Specs are grouped by domain (`specs/<domain>/<name>.md`) with an `INDEX.md` per folder and a root `specs/INDEX.md`, so a spec is found by reading two short indexes instead of a flat folder of 333 files. The audit that came with it deleted 27 obsolete specs (finished migrations, superseded or duplicated specs, implementation plans), moved 3 studies to `docs/rapports/`, folded the 21 HTML mock-ups into their specs, and corrected the specs that no longer matched the code.
- The `spec rules` CI job reads the domain folders, refuses two specs with the same name, and refuses a citation to a spec path that does not exist; `node scripts/rewrite-spec-paths.mjs` rewrites stale paths after a move or a merge.
