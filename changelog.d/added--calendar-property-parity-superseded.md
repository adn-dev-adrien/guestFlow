- **Duplicates set aside** (spec `calendar-property-parity.md` rules 22-24). A stay that the old « platform disabled » filter hid and that sits on a visible stay of the same logement, with no money in, is set aside as a duplicate (`kind = 'superseded'`): out of every calendar, list, availability check and the books, still found by the search (« Doublon écarté »). Its fiche is read-only and an admin can « Rétablir » it. The iCal sync never resurrects it.
