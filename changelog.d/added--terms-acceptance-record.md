- **CGV written in GuestFlow, acceptance recorded on every website booking** (spec `terms-acceptance-record.md`, 2026-09-22). New page Paramètres → Conditions générales: Markdown FR + EN with variables (`{{raisonSociale}}`, `{{cautions}}`…), server-rendered preview, publication as an immutable numbered version (frozen HTML + SHA-256), stale-fact warning when a quoted value changes. Public booking requests must carry the current version: GuestFlow records the acceptance with its own clock, the version, the visitor's IP / browser and the plugin version, in the same transaction as the devis, and refuses a request without it (`422 TERMS_NOT_ACCEPTED`), on an outdated version (`409 TERMS_OUTDATED`) or while nothing is published (`503 TERMS_NOT_CONFIGURED`); an emergency switch lifts the enforcement. The fiche shows « CGV v3 acceptées le … » with the proof and the accepted text; the history logs it; the confirmation email links to `/cgv/?v=N` (`{{cgvUrl}}`). New public routes `GET /public/v1/terms[/:version]`. +41 server tests, +13 client tests.
