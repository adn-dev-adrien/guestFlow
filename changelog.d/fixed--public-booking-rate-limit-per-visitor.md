- **Booking anti-spam limit applied to the whole site** — every public call reached GuestFlow from the WordPress host's single address, so `bookingRequestLimiter` (5 / hour) capped the entire site. The plugin now relays the visitor (`X-GuestFlow-Visitor-IP`, honoured only after the API-key check) and the three public limiters count per visitor; an unauthenticated call is refused before being counted (spec `terms-acceptance-record.md` §3.6).
