- **Activation hooks (SDK 2.11.0) fire when the licence turns a plugin live, and only after an install committed.** A plan upgrade that starts allowing an already-enabled plugin now runs its `ctx.onActivate` hook once; a requirement rolled back with its dependant no longer announces itself. An install that needs a restart still fires nothing at the next boot (known limit, spec `plugin-removal-resilience.md` rule 17).
