- A devis open in the editor no longer loses the guest's new website message (nor the « modified after sending » flag) when saved: a save built on an out-of-date devis is refused with the « Fiche modifiée entre-temps » dialog (reload / save anyway / cancel), like the reservation fiche.
- Two overlapping iCal syncs of one source (5-minute pass, « Synchroniser », « Synchroniser tout ») now share one run, so a single empty answer from a platform can no longer be counted twice and wipe the source's mappings.
- Google Agenda plugin 1.2.3: a push and a delete of the same stay run in order, so a cancellation arriving while the stay is being pushed no longer leaves its event in the calendar. A Google call that never answers is now aborted after 20 s and retried at the next sync, instead of holding the stay's queue for minutes.
