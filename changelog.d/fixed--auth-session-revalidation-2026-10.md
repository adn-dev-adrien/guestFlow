- **Sessions are now re-validated and revocable** (spec `security-auth-encryption.md` rules 3 & 7, 2026-10). Every `/api` request re-reads the user row, so deactivating, deleting or demoting a user ends their open session on the next request instead of letting the login snapshot live for the 30-day window. Deactivation, admin password reset and role changes revoke all of a user's sessions; a voluntary password change logs out every other device; the session id is regenerated on login (anti-fixation). Closes 2026-10-08 audit findings AUTH-1, AUTH-2 and AUTH-6 (sessions). +13 server tests.
