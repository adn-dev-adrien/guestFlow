- **A plugin that is gone no longer takes the server down** (spec `plugin-removal-resilience.md` rules 1, 2, 6). The plugin catalogue is built from the manifests that exist: a plugin whose folder is missing is skipped with one log line instead of crashing the boot, and an installed plugin whose code is gone is listed « Paquet introuvable : à réinstaller. » on the Plugins page, where it can be uninstalled. A plugin with no loaded module is never live, in development as in production (`/api/auth/me` no longer lists it). A stored open payment link is re-offered in the deposit reminder and in an installment request only while a payment provider is live.
