- **A test line with a literal date fails the pull request** (`server-test-isolation.md` rule 7). `node scripts/check-test-dates.mjs --base <ref> --strict` names the dates from today on in the test lines a PR adds, and the `spec rules` job fails on them; `// date-literal-ok: <why>` marks a date nothing compares with today. A clock pinned or injected in one test (`vi.setSystemTime`, a stubbed `getTodayIsoDate`, a `NOW` constant, a `now:` handed to the code) exempts that test only, a pin in a helper the tests that call it, and a timer mock that leaves `Date` real exempts nothing.
