- **Support access (H2 review):** a support session can no longer reach a forbidden route by changing the letter case or adding a trailing slash, nor decide or revoke its own access by any path; it writes no account and no credential (users, SMTP group, plugin secrets, Google and Qonto connections, Neat), reads no clear-text secret (gate connector) and cannot uninstall or turn off a plugin; its reads are logged once a minute and the customer reads the log in plain French (« Réservation 12 modifiée », « Refusé »); the support account is told by a flag, cannot be edited and is never restored by `reset-admin.js`; a managed instance accepts support only for its own slug, taken from the licence when `GUESTFLOW_SLUG` is not set (specs/hosting-h2-account-security.md rules 15, 18-22).
- **Forgotten password:** the answer leaves before the address is looked up, a caller over the IP limit no longer uses up an address's quota, and the counters stay bounded in memory.
- **Second step:** « Utiliser un code de secours » switches the code field to the letter keyboard; the backup codes dialog closes on « Terminé » only; the red support bar keeps clear of the phone's home indicator.
