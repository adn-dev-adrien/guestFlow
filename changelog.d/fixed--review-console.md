- **Console — a lost invitation is no longer a dead end** (spec `hosting-h1-fleet-runtime.md` rule 24, review 2026-10-18). « Reprendre » on a failed invitation now issues a new provisional password and sends it again; the customer's page offers « Renvoyer l'invitation » and « Réinitialiser l'accès » (second step turned off), each journaled.
- **Console — new instances start with what the console knows** (rule 25). Their environment carries `GUESTFLOW_PUBLIC_URL`, `GUESTFLOW_REGISTRY_URL` and the registry's key, rewritten at a rename; the establishment (name, contact email, address, VAT number) is seeded at creation, so onboarding is pre-filled, « mot de passe oublié » works and the platform mails get their Reply-To. Réglages › Système shows the hosting's address as the public URL's default.
- **Hosting bootstrap** (rules 26–27): `bootstrap-host.sh` generates the licence key pair and takes the object storage keys once (`S3_ACCESS_KEY_ID` / `S3_SECRET_ACCESS_KEY`), rewriting `/etc/default/litestream` from the console's env; rclone's remote is derived from `CP_BACKUP_URL` (no `rclone config`). The runbook says the repository is public and lists the licence key among what is kept offline.
- **Console — Versions** (rule 28): a release an update rolled back reads « En échec » and is never the default target; no scope is preselected.
- **Console — crashed instance** (rule 29): « Redémarrer » on the customer's page (systemd's failure reset first); host alerts link to the customer's page, in the console and in the email.
