- **Public API, additive** (specs/public-api.md; website-booking plugin 1.2.0, SDK 1.3.0): `GET /public/v1/properties/:id/availability` returns `nextAvailableDate`, the first bookable arrival on or after the window (free nights that pass the minimum/maximum stay and the arrival/departure days), looked up to a year ahead (`null` when none). A refused contact field of `POST /public/v1/booking-requests` carries `reason` and a `message` in the request's language under `details[]`, and the summary message reads « Coordonnées incomplètes ou invalides. » The SDK exposes the core module `changeover` and `pricing.calculateBaseStayPrice`.
