- Production now serves HTTPS through a **Caddy reverse proxy** on the Pi instead of Node terminating TLS itself: `domainesolio.com` → WordPress, `guestflow.domainesolio.com` → GuestFlow. Caddy obtains and auto-renews the Let's Encrypt certificates (no cron, no script). New `scripts/setup-reverse-proxy.sh` + `deploy/caddy/Caddyfile` set it up on the Pi.
- GuestFlow now always serves plain HTTP on `:4000`; the new `HTTPS_EDGE` env var (replaces `HTTPS_ENABLED`) tells it an HTTPS edge is in front so it keeps emitting HSTS, CSP `upgrade-insecure-requests`, and the `Secure` session cookie.
