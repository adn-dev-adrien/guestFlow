- **The bank reconciliation start date is held to the date window** (specs/qonto-bank-reconciliation.md rule 48, audit R20-P1): « Mise en service » on the « Rapprochement bancaire » card was only checked by a `YYYY-MM-DD` regex, so `2027-02-30`, `0002-10-31` or `9999-12-31` were saved, leaving the reconciliation silently empty or asking Qonto for the account's whole history. The server now refuses an impossible day or one outside today ± 5 years; the stored value keeps saving. The field hints the same window from the server's day.
- plugin:online-payment The reconciliation start date is a real calendar day within five years of today; the date already stored stays accepted.
