- **Bounded numbers in the settings** (specs/settings-input-guards.md): the acompte delay runs from 0 to 30 days, the solde and annulation delays from 0 to 60. A minus sign is removed as it is typed, a text that is not a number brings the previous value back when the field is left, and an out-of-range value turns the field red and is refused by the server instead of being silently replaced (a negative delay used to be saved as 7). A delay of 0 reads « à régler à la réservation ». The commission and payout fields of Paramètres › Plateformes behave the same way, and the old per-platform commission endpoint now refuses a negative or excessive rate instead of clamping it. A stored delay outside the new bounds is left alone until it is edited.
