- **iCal sync no longer applies a stale feed** (spec `ical-sync-mapping-resilience.md` rule 8, audit R5-1, 2026-10-30). The 5-minute pass fetches every feed at once and applies them in turn; a feed fetched before an operator sync of the same source is now dropped, and one outage seen by both is counted once, so it no longer wipes a source's mappings nor raises a false « annulation à valider » for a stay just created.
- plugin:google-calendar The full reconcile pushes each stay in the per-reservation order and re-reads it first, so a stay cancelled or edited while it runs is not recreated or reverted in Google (spec `google-calendar-oauth-rework.md` rule 28, audit R5-2, 2026-10-30).
