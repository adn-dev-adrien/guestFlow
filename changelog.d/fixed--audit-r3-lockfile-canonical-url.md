- **Security: a release lockfile entry must now be spelled exactly as npm will fetch it** (specs/self-update-and-releases.md rule 49): the check that each dependency comes from its own registry tarball compared a raw string prefix, so a `resolved` URL with `..` segments passed the check while npm downloaded another package. The URL must now be canonical, on `registry.npmjs.org`, without query or fragment, and end with the package's own `<name>-<version>.tgz`.
