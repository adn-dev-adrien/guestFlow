- **Une erreur Qonto dit enfin ce qu'elle est.** Qonto répond avec deux enveloppes différentes selon l'endpoint ; GuestFlow n'en lisait qu'une, et affichait « Qonto a renvoyé une erreur — HTTP 400 » alors que la réponse contenait déjà la cause. Le code et le détail donnés par Qonto remontent maintenant dans Réglages → Paiements dans les deux cas. En particulier, un lien de paiement refusé parce que le provider de liens n'est pas connecté est nommé comme tel et renvoie au formulaire qui le répare, au lieu de conseiller de contacter le support pour un problème réglable sur place en une minute.
