- **Plans and subscriptions, inside each instance** (specs/control-plane-plans-and-access.md, C1): an instance hosted on the GuestFlow platform reads a signed licence from its data directory. A plugin outside the customer's plan shows its plan (« Forfait Pro ») and cannot be installed; one installed before a downgrade reads « Désactivé — hors forfait » and keeps its data. Units and accounts beyond the plan's quota are refused. An unpaid subscription shows an admin banner, then turns the instance read-only: reads, exports, the calendar sync and collecting payments keep working, and the website stops taking new bookings. The login page fills in the email passed by the shared login page (`?login_hint=`).
- An install that is not hosted on the platform and has no licence file (Solio today, dev machines) is unaffected: every plugin, no quota, no banner.
