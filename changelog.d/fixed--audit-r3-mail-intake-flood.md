- **Mail intakes (SDK 2.15.0):** a pass no longer downloads and holds every mail of the sender from the last 30 days. Known Message-IDs are skipped before the body is downloaded, mails are processed one by one, a pass reads at most 200 (newest first), and messages that are not intakes or are too large are remembered as `ignored`. The four mail-related plugins (website-booking 1.8.6, booking-intake 1.3.8, airbnb-intake 1.1.3, gites-de-france-intake 1.4.5) now require SDK 2.15 so an older core refuses them instead of running without the core hardenings.
- **Gîtes de France and Airbnb intakes in a published package:** the intake service no longer requires `./manifest.json` (absent beside the code in a built package, it made the pass, the dashboard line and every fiche block fail with a 500). Plugins read their version with the new `sdk.manifestVersion(__dirname)`.
