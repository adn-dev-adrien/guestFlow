- **Hosting H1 — the console runs the fleet** (`specs/hosting-h1-fleet-runtime.md`): creating a customer provisions its instance by itself (directory, secrets, port, database, first admin, systemd unit, Caddy site, health check, Litestream replica), each step shown live with « Reprendre » on a failure; stopping, reactivating, renaming (301 for 90 days) and erasing need no shell. New console page « Versions »: releases installed once per host (SHA-256 verified) and updates one instance at a time with automatic rollback on a failed health check. The fleet shows real version, process, backup, verified restore, disk and certificate; a probe raises alerts (down, backup lag, disk, certificate, memory, email quota) emailed once then every 24 h; every Sunday each backup is restored and checked; « Restaurer à une date » on the customer page. Host files and runbook in `deploy/hosting/`.
