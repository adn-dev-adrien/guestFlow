- **Connexion Qonto en clé API (au lieu d'OAuth)** (spec `online-payments-qonto.md` §4.1/§10, 2026-06-26). GuestFlow automatise **ton propre** compte Qonto : on passe de l'OAuth2 (app + redirect URI + consentement) à la **clé API** Qonto (`Authorization: {login}:{secret-key}`), recommandée par Qonto pour ce cas — plus simple, et **sans validation Qonto en production** (l'OAuth avec le scope liens de paiement l'exige). `qontoClient` choisit le mode **clé API** dès que `QONTO_API_LOGIN` + `QONTO_API_SECRET_KEY` sont présents dans `.env.local` (sinon repli sur l'OAuth conservé). Le bouton « Connecter Qonto » est masqué en mode clé API ; la connexion du provider de liens (KYC Mollie) reste inchangée. +2 tests serveur.
