- **Booking, Airbnb and Abritel can leave Lodgify and sync by iCal directly with GuestFlow.** A native Booking feed is read even though Booking labels every taken night « CLOSED - Not available »: an event on free dates becomes a Booking reservation, an event that only mirrors nights GuestFlow already holds (another channel's stay, a closure, a stay cancelled less than 72 h ago) is ignored as an echo, and an event overlapping held nights is created with the conflict badge and an alert. A native feed takes over, without duplicating it, the stay the Lodgify relay had imported for the same channel on the same dates; the Lodgify source then skips it for good. The sync message counts « reprise(s) », « écho(s) ignoré(s) » and « en conflit » (`specs/lodgify-decommission.md`).
