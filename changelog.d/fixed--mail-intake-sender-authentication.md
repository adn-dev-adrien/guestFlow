- **Mail intakes (Airbnb, Gîtes de France)** no longer trust a forged sender: only mails whose envelope From address equals the configured sender are read, and a mail without `dkim=pass` for the sender's domain in the mailbox server's `Authentication-Results` is stored as a proposal flagged « Expéditeur non vérifié », never auto-applied. An authenticated Gîtes de France mail never replaces the e-mail or phone already on the fiche. The mailbox password is only sent over TLS (STARTTLS required off port 993) and only to a host of the SMTP server's domain; the IMAP host/port, sender and signature settings are refused to a support session. SDK 2.12.0 (`mailbox.resolveImapHost`, `readMailsFrom` returns `authenticated`).
