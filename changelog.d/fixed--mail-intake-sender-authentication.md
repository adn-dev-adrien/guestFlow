- **Mail intakes (Airbnb, Gîtes de France)** no longer trust a forged sender: only mails whose header From address equals the configured sender are read, and a mail without `dkim=pass` for the sender's domain in the `Authentication-Results` written by the mailbox's own server (Gmail by default, otherwise the « Serveur de réception » setting; an RFC 8601 tokenizer reads it) is stored as a proposal flagged « Expéditeur non vérifié », listed on the dashboard, never auto-applied. An authenticated Gîtes de France mail never replaces the e-mail or phone already on the fiche. The mailbox password is only sent over TLS (STARTTLS required off port 993) and only to a host of the SMTP server's domain — pinned inside the SDK, so it holds for any plugin version; the IMAP host/port, sender and signature settings cannot be changed by a support session, which can no longer roll a plugin back or update it to a chosen version. SDK 2.12.0 (`mailbox.resolveImapHost`, `readMailsFrom` returns `authenticated`).
