- **Open orphan payment links withdrawn once** (`orphan_payment_links_withdrawn_v1`, spec `payment-link-lifecycle.md` rule 5). At the first boot, every `open` payment link whose stay row is missing becomes `cancelled` with `cancelReason = 'orphan'` and, when it has a provider id, the deactivation marker; one `[migration:orphan-links]` line is logged per link. No network call at boot: the first poll pass reads each link's payment, then deactivates it (`[payments] orphan link #… deactivated at …`) or sends the orphan alert if it was paid meanwhile. Paid, cancelled and expired rows are untouched; nothing is deleted.
