- **Plugin SDK 2.0.0** (specs/sas-arrival-total-server-side.md rules 13-14bis): the client step contract `sas.arrival.steps[].recapLines` is removed — a step bills through its server `ctx.sasCommit().complementItems`, which the arrival preview now calls on every gesture and which must therefore be pure. Every plugin of this repository moves to `sdk: "^2.0.0"` in this release and installs with it. **A plugin installed from outside this repository and built against SDK 1 is refused by this version until its author republishes it against `^2.0.0`**; none is known today.
