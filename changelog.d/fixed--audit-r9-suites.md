- **A server suite can no longer report green with tests left unrun** (audit R9 M-1, `server-test-isolation.md` rules 5 and 10). Under load, `--test-force-exit` ended a test file's process before its last tests and the run stayed green — on GitHub CI 12 tests of `sas-commit.unit.test.js` went missing from a green job. The server and control-plane suites drop it: an exit watchdog now fails a file still alive 30 s after its last test (a hanging test still fails, named, on Node 22 and 24), and a completeness reporter fails the run, naming the tests, whenever a file's process ends before reporting every test it declared.
- **A planning test no longer fails on a loaded machine** (audit R9 L-1). `ResourcePlanningPage.stale-bookings` waits up to 5 s for the page's first paint instead of 1 s.
