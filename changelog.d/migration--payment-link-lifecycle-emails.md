- **The default payment e-mails gain their validity sentence, on untouched templates only** (`payment_link_valid_until_sentence_v1`, spec `payment-link-lifecycle.md` rule 36). At the first boot, the French body and the English body of `deposit_request`, `balance_request`, `full_request`, `installment_request` and `deposit_reminder` each get the sentence « Ce lien est valable jusqu'au {{paymentLinkValidUntil}}. » / « This link is valid until {{paymentLinkValidUntil}}. » after the link only when they still hold, to the character, one of the default texts GuestFlow shipped for that template (any version, so an install seeded with an older default is recognised too); nothing else in the text changes. A side the operator edited keeps its text exactly and is named in the boot line `[migration:link-valid-until] …; edited, left as they are: …`; the variable is available to add by hand. No sending mode changes (every template stays Manual); nothing is deleted.
