- **Plugin removal matrix** (spec `plugin-removal-resilience.md`). A nightly and on-demand workflow removes each plugin from the code in turn and checks that the server suite, the build, the production server on a database still holding its data, the core API, the core pages (desktop and phone) and the saved fiches all keep working, then a sweep deactivates, uninstalls, purges and reinstalls every plugin on a running server. `node scripts/plugin-removal.mjs cell <id>` runs one cell locally on a copy of the tree. The test suites name the plugins they need and skip when one is not shipped.
