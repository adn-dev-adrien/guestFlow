- **Links already open get 36 hours from the install** (`payment_link_validity_backfill_v1`, spec `payment-link-lifecycle.md` rule 34). At the first boot, every `open` payment link — Qonto's `0001-01-01…` sentinel and complement links included — gets `expiresAt = install + 36 h`, one `[migration:link-validity]` line per link; they then lapse like any link, so operators re-send the requests still wanted. Two nullable columns are added to `payment_links`: `lastLookAt` and `deactivationAlertedAt` (additive: the previous release ignores them). Nothing is deleted; paid, cancelled and expired rows are untouched.
