- **Neat — bounded calls** (spec `neat-cancellation-insurance-subscription.md` rule 17, round-6 audit N6 and review D1). Each Neat client call has one 5 s budget shared by auth, request and 401 retry (headers and body read included), and the quote processor reuses one client and token per account. After an outage (timeout, network error, 5xx) guest pricing skips Neat for 60 s; a 4xx never opens that breaker. A hanging or degraded Neat no longer holds the public quote or the fiche preview beyond the WordPress plugin's 8 s: the fallback ladder (stale cache, then static tariff) runs inside it. Neat plugin 1.3.3.
