- `release.sh` builds the server part of the archive from tracked files only and refuses a staging tree that carries a secret or a runtime file (`.env.local`, databases, `licence.jws`, keys, uploads), so a manual release can no longer ship a developer's secrets (specs/self-update-and-releases.md rule 42).
- `npm test` gives every server test process its own throw-away database and makes opening the checkout's `server/guestflow.db` an error; three tests that used to migrate it now set their own (specs/server-test-isolation.md).
