- **Plugins are set up by the operator, from the console** (spec `plugin-operator-provisioning.md`, 2026-10-28). The customer page has a « Modules » section: one switch per module the plan allows, saved at once, with the state the space actually reports (active, waiting, failed, blocked, to configure). The choice travels in the signed licence (`activePlugins`) and the space applies it within a minute, with no restart and no new listening port. « Nouveau client » ticks the plan's modules. A space not yet read is seeded from what it runs before any licence carries the choice, so no existing space changes. +46 server tests, +13 console client tests.
- **Erasing one module's data, from the console** (spec `plugin-operator-provisioning.md`, rules 22–23). On an inactive module that still holds data, « Effacer les données… » lists what will be erased and asks for the customer's slug typed. The order travels once in the licence; the space runs it through the existing purge, and the console closes it when the space reports it done. A hosted space keeps its continuous backup. +7 server tests, +3 console client tests.
