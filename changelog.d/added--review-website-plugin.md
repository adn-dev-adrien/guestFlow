- **Website, set up in two pastes:** Paramètres › Intégrations › « Site internet (WordPress) » shows the API URL and the key to paste into WordPress, masked with « Copier », and « Régénérer la clé ». The WordPress plugin (1.15.0) derives the rest: the default lodging is picked by name from GuestFlow's list, the booking and CGV pages are found by their content or created in one click, a reverse proxy on the local network is recognised without a setting, and the connection is tested when the settings page opens.
