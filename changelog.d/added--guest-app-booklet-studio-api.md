- **Guest app « Mon séjour », slice E (server)** (spec `guest-app.md` rules 1, 11ter, 15bis, 16-21, 47-49). One booklet per lodging: pages placed in each lodging's booklet in its own order (published or not there), shared between lodgings and edited once, blocks restricted to some lodgings, « Dupliquer vers… » for an independent copy; « Publier » freezes one lodging's booklet and republishes a shared page in every lodging it is placed in. Guests read the last published version (`GET /public/v1/guest/booklet`, `/booklet/pages/:slug`, `/booklet/search`, by session or by the printed code), in their language with the French as fallback per field; the `wifi` and `contact` blocks read the lodging's own facts (« Pas de wifi » when it has none), and a button to an item the session cannot buy is not sent. The studio API (`/api/guest-app/studio/**`) edits pages and the closed list of eleven block types, rich text sanitised on the server, previews and searches the draft (accents ignored), counts the untranslated texts, and uploads photos (JPG, PNG, WEBP up to 10 Mo, stored at 1600 / 800 / 400 px in WebP under `/uploads/guest-app/`). `POST /api/guest-app/lodgings/:propertyId/regenerate-qr` kills a lodging's old code at once, `GET …/qr-poster.pdf` prints the A4 poster. A lodging entering the app for the first time gets five neutral placeholder pages. `/me` gains `suggestion`: the one dated Soliomap event of the days left (read from Soliomap's feed, cached an hour, nothing when Soliomap does not answer within 5 s). SDK 2.25.0 also exposes `safeFeedFetch` (the public-only outbound fetch of the iCal import) and `instancePaths.uploadsDir`.
