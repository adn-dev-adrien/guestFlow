- **A silent push endpoint no longer stalls the payment poll** (spec `pwa-push-notifications.md` rule 14, audit R7 N7, 2026-10-30). Each web push send is bounded at 10 s (web-push socket timeout plus a hard deadline) and counts as failed past it, so the online-payment poll, the Qonto webhook, the Neat pass and the per-minute push runners can no longer stay blocked behind a push endpoint that accepts the connection and never answers.
- plugin:google-calendar The token revocation of « Déconnecter » carries the same 20 s bound as the other Google calls, so a silent Google endpoint no longer holds the disconnect request (spec `google-calendar-oauth-rework.md` rule 30, audit R7, 2026-10-30).
