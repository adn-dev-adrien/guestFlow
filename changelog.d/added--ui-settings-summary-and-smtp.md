- **Paramètres — summary page, four groups and search** (`specs/settings-rationalization.md` rules 24–27; UI/UX review 2026-10-18, proposal 20 and decision 12). « Paramètres » opens a summary: each page on one row with a state line computed by the server (`GET /api/settings/summary`: « 2 logements », « Envoi non configuré », « 12 actifs · 4 à configurer »…), in four groups (Établissement, Séjours, Paiements et emails, Compte et système), with a search that understands wifi, iban, smtp, 2fa. The sidebar submenu shows the four groups and unfolds only the open page's group (at most 9 rows instead of 15). Intégrations moves next to Plugins.
- **Envoi — the sending server deduced from the address** (rule 28, decision 14). The server recognises the provider from the address's domain or its MX records (DNS only, `POST /api/settings/smtp-detect`) and fills host and security at save when none is configured and a password is there; a configured host always wins, a provider not found opens the manual fields. Server, login and security now sit under « Réglages avancés »; the disabled test button says what it waits for.
