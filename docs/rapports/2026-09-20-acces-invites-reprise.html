La suite Playwright a tourné. Elle n'avait jamais été lancée parce qu'il faut l'app entière debout — or elle est le job « smoke » de la CI guestFlow. Sur #563 : 68 tests, tous verts en 1 min 42. Ce point de la liste est clos.

Ce qui a dû être corrigé en poussant

1 · La base de guestFlow avait bougé

Le patch visait un master antérieur à la séquence de mails (#561, fusionnée depuis). Rebranché sur origin/master, trois conflits d'union résolus à la main : les exports du contrôleur des réservations, la signature de buildContext et les require de l'expéditeur de mails. Aucune logique arbitrée — la séquence de mails et l'invitation cohabitent.

2 · La CI du cœur exige trois documents

check-specs-complete.sh refuse tout nouveau dossier de spec sans spec.md + architecture.md + plan.md. Le patch n'apportait que le premier. Les deux autres ont été écrits d'après le code livré : l'architecture réelle des trois surfaces, et le plan de test par module derrière les 44 cas.

3 · CodeQL bloquait la PR du cœur

Deux alertes hautes sur queryOf : les clés de la query string étaient écrites dynamiquement dans la carte remise au plugin. Ni un garde-fou par liste, ni Object.create(null) ne le taisent — c'est l'écriture out[key] = v qui est signalée. Object.fromEntries la fait disparaître. Un cas de test en plus (24 maintenant).

4 · Les commits étaient signés « Claude »

Héritage du format-patch. Réécrits à ton nom sur les trois dépôts adn-dev-adrien, trailer Co-Authored-By conservé. Le commit de la PR du cœur, lui, était déjà à ton nom et n'a pas été touché.

L'adresse des clients

Le cœur sert la page sous /p/guest-access/, un chemin qu'il impose. Ce n'est pas une adresse à lire dans un e-mail. Le choix retenu est un alias, pas une redirection : une 301 ferait apparaître sowel.adn-dev.fr dans la barre d'adresse du client dès l'ouverture.

acces.domainesolio.com {
    rewrite * /p/guest-access{uri}
    reverse_proxy sowel:3000
}

Côté plugin, deux réglages : guest_base_url = https://acces.domainesolio.com et guest_path = /.

La réécriture doit couvrir tout l'arbre, pas seulement /. La page appelle app.js, style.css, icon.svg et enrol relativement à elle-même : une règle qui ne prend que la racine donne une page nue qui a l'air de marcher. C'est exactement ce que le test au téléphone, plus bas, vérifie.

Le code reste dans le fragment (#i=CODE) dans toutes les variantes — un fragment n'est jamais envoyé à un serveur, donc aucun journal n'en voit passer. Côté guestFlow le lien est opaque : il stocke et affiche la chaîne qu'on lui pousse, il n'en construit, n'analyse ni ne réécrit jamais aucune.
