# Devis — quotes stored as reservations (kind='devis'), their fiche, conversion and PDF

Start with: `devis-reservation-fusion` (a devis is a reservation row; everything else follows). See also: `pricing/`, `payments/`, `tourist-tax/`, `site/` (public quotes, translation catalogue).

- `devis-reservation-fusion` — A devis is a `reservations` row with `kind='devis'`, `devisNumber`, `devisStatus`, `validUntil`; every occupancy, finance and iCal query filters `kind='reservation'`; boot migration folds legacy `devis_*` tables. Code: `server/src/models/devisModel.js`, `server/src/utils/devisFusionMigration.js`.
- `devis-extras-parity-and-price-lock` — Devis persists and prices exactly like a reservation (planning cards, hourly sessions, Complément flags); sold prices stay locked until `validUntil`, expired quotes re-price; conversion carries the full line graph. Code: `server/src/models/bookingLinesModel.js`, `server/src/models/devisModel.js`, `client/src/utils/bookingFormHydration.js`.
- `devis-accept-to-reservation` — Status « Accepté » is the single way to convert: confirm, save, convert, land on the reservation; conversion refuses taken dates (409) and missing stock. Code: `client/src/pages/ReservationPage.jsx`, `server/src/models/devisModel.js`.
- `devis-pdf-and-tourist-tax-fixes` — Devis dates and validity (`createdAt`, `validUntil` from `quoteValidityDays`, floors and caps), property option defaults merged server-side, tourist-tax detail line from the engine quote. Code: `server/src/utils/devisValidity.js`, `server/src/utils/devisPdf.js`.
- `devis-pdf-total-parity` — PDF TOTAL equals printed rows plus tax; the quote replays the sold state via `devisModel.recomputeQuote`, shared by payment links; expired devis print sold prices. Code: `server/src/models/devisModel.js`, `server/src/utils/devisPdf.js`.
- `devis-pdf-row-layout` — Each pricing-table row is as tall as its measured content; badge on its own line above the label; struck original reserves a line. Code: `server/src/utils/devisPdf.js`.
- `devis-offered-resource-parity` — An offered resource is stored at 0 €, printed « Offert » with its real price struck, and never deducted from the accommodation row. Code: `server/src/models/bookingLinesModel.js`, `server/src/utils/devisHelpers.js`.
- `devis-english-language` — Per-devis `pdfLanguage` (fr/en) drives every PDF label, date format and footer; English option and resource names come from the translation catalogue. Code: `server/src/utils/devisPdfLabels.js`, `server/src/utils/devisPdf.js`, `client/src/pages/ReservationPage.jsx`.
