# Reservations — the reservation fiche: saving, locks, capacity, history, numbers, terms

Start with: `reservation-save-keeps-pricing` (what a save may and may not re-price). See also: `pricing/`, `payments/`, `sas/`, `clients/`, `emails/`.

- `reservation-save-keeps-pricing` — a save that moves no pricing input keeps the stay as priced; one engine input for a stored stay; trop-perçu measured against the stored price. Code: `server/src/controllers/reservationsController.js`, `server/src/models/reservationsModel.js`.
- `reservation-fiche-concurrency` — the save carries `loadedUpdatedAt`; a stale version is refused `STALE_FICHE` with an overwrite dialog; background writers bump `updatedAt`. Code: `server/src/controllers/reservationsController.js`, `client/src/pages/ReservationPage.jsx`.
- `edit-reservation-blocked-by-overlap` — overlap and capacity guards run only when placement or occupancy changed, so finance-only edits are never blocked. Code: `server/src/controllers/reservationsController.js`, `client/src/utils/reservationConflicts.js`.
- `admin-unlock-past-reservations` — past or started stays are locked; an admin unlocks one fiche (`unlockPast`), ending on leave or reload. Code: `server/src/controllers/reservationsController.js`, `client/src/pages/ReservationPage.jsx`. **[Superseded in part]**
- `reservation-option-immutability` — a created reservation's options and billed amounts are frozen against catalogue changes; update never adds property defaults. Code: `server/src/controllers/reservationsController.js`, `client/src/pages/ReservationPage.jsx`.
- `manual-price-on-placement-change` — moving a stay with a manual accommodation price opens a server-computed review: keep gap, keep amount, or follow the tariff. Code: `server/src/utils/manualPriceReview.js`, `client/src/components/reservation/ManualPriceReviewContent.jsx`.
- `property-capacity-single-total` — capacity is `maxGuests` (over 2 years) plus separate `maxBabies`; back-office warning can be forced, public API refuses. Code: `server/src/utils/capacity.js`, `server/src/plugins/website-booking/controllers/publicBookingRequestController.js`.
- `reservation-history-granular-diff` — history lists one row per changed thing, per option or resource line, values formatted in French, engine recalculations grouped apart. Code: `server/src/utils/reservationAudit.js`, `client/src/components/reservation/ReservationHistoryPanel.jsx`.
- `reservation-number-and-search` — `AAAAMM###` reservation number, header live search by number, name or phone, administrator only. Code: `server/src/utils/reservationNumber.js`, `server/src/models/reservationsModel.js`.
- `terms-acceptance-record` — CGV written and versioned in GuestFlow, published to the site, acceptance recorded per request; unaccepted public requests refused. Code: `server/src/controllers/termsController.js`, `client/src/pages/settings/TermsSettingsPage.jsx`.
- `reservation-form-sections` — left column split into Stay, Guests and beds, Extras, Finance sections reading one `ReservationFormContext`; labels readable at every width. Code: `client/src/components/reservation/ReservationFormContext.jsx`, `client/src/components/reservation/StaySection.jsx`.
- `reservation-page-action-bar` — the fiche uses the shared `PageActionBar` (`onBack`, custom node actions, `center` slot with client and number). Code: `client/src/components/PageActionBar.jsx`, `client/src/pages/ReservationPage.jsx`.
- `reservation-client-inline-edit` — bold client name opens the client fiche; « Changer le client » reveals the search; « + créer un nouveau client » beside it. Code: `client/src/pages/ReservationPage.jsx`, `client/src/components/ClientFormFields.jsx`.
- `reservation-quantity-stepper` — `QuantityField`: draft while typing, commit on blur or Enter, `−`/`＋` steppers, never drops an option when emptied. Code: `client/src/components/QuantityField.jsx`, `client/src/components/reservation/ExtrasSection.jsx`.
- `reservation-price-arithmetic` — price fields evaluate typed expressions (`100+20`) on Enter or blur, safe parser, currency and thousands separators tolerated. Code: `client/src/utils/arithmetic.js`, `client/src/components/ArithmeticTextField.jsx`.
- `free-text-keeps-case` — free-text notes keep the operator's capitals (`capitalizeFirst`); names use `personNameCase`; labels keep `sentenceCase`. Code: `server/src/utils/textFormatters.js`.
- `admin-public-request-visibility` — Devis list flags website-origin requests with a « Site internet » badge and an « Origine » server-side filter. Code: `client/src/pages/DevisPage.jsx`, `server/src/models/devisModel.js`.
