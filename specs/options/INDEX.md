# Options — the option catalogue, per-property scope/price/defaults, and planning-card options (breakfast, meals)

Start with: `options-resources-ux` (the Options & Resources catalogue page and its payload rules). See also: `resources/`, `linen/`, `sas/`, `pricing/`, `reservations/`.

- `options-resources-ux` — Options & Ressources page: catalogue read by category, side editor panel, one « Logements et prix » table per option, archive section, server-owned payload clean-up. Code: `client/src/pages/OptionsResourcesPage.jsx`, `client/src/pages/options/OptionEditorPanel.jsx`, `server/src/models/optionsModel.js`.
- `option-categories` — Option categories: collapsible groups on the reservation form and public widget, `category`/`seedKey`/`alwaysVisible` columns; catering seed is gone. Code: `server/src/utils/optionGrouping.js`, `server/src/utils/optionCategoriesMigration.js`, `client/src/components/reservation/ExtrasSection.jsx`.
- `option-property-scope` — « Tous les logements » is an explicit choice (links to every current property); empty scope = available nowhere. Code: `server/src/models/optionsModel.js`, `client/src/pages/OptionsPage.jsx`.
- `option-soft-delete` — Deleting an option archives it: hidden for new bookings, preserved on existing reservations, restorable. Code: `server/src/models/optionsModel.js`, `client/src/pages/OptionsPage.jsx`.
- `per-property-option-prices` — Per-property price overrides on any option (`property_option_prices`), blank = base price, 0 = free. Code: `server/src/models/optionsModel.js`, `server/src/utils/pricing.js`.
- `per-property-default-options` — Any option can be « Inclus »/« Offert » by default per property (`property_option_defaults`), future reservations only. Code: `server/src/models/propertyOptionDefaultsModel.js`, `server/src/controllers/propertyOptionDefaultsController.js`.
- `property-default-option-applicability` — A property's default options always apply to it (bed-linen card on every Gîte reservation), regardless of scope links. Code: `server/src/models/propertyOptionDefaultsModel.js`, `client/src/pages/ReservationPage.jsx`.
- `import-price-default-options` — iCal/Lodgify import prices paid default options through the engine; free ones stay 0. Code: `server/src/models/propertyIcalModel.js`.
- `welcome-pack-auto-options` — Own-channel reservations get the welcome pack (breakfast for 2 + apple juice) auto-added from `freeUnits`. Code: `server/src/controllers/welcomePackController.js`, `server/src/utils/pricing.js`.
- `baby-bed-supplement` — « Lit bébé » auto option bills price × cots once per stay (seeded at 0 €); not a linen item. Code: `server/src/utils/babyBedSupplement.js`, `server/src/utils/babyBedSupplementSeed.js`.
- `custom-option-amount-comma` — Custom option « Prix TTC » accepts a French comma and the line survives quote recomputes. Code: `client/src/components/reservation/ExtrasSection.jsx`, `client/src/utils/applyQuoteToForm.js`.
- `option-planning-card` — A flagged option (« Repas ») gets default date/time, per-day occurrences and a Planning card; empty selection is now handled by `unscheduled-card-option`. Code: `server/src/models/planningOptionCardsModel.js`, `client/src/components/OptionDayCard.jsx`.
- `unscheduled-card-option` — A card option sold without moments keeps its line, flagged « à planifier », and can be planned later; the SAS planning step (rule 8) is deferred. Code: `server/src/utils/pricing.js`, `client/src/components/PricingSummary.jsx`.
- `card-option-served-persons` — « Personnes servies » on card options: billed covers can be lower than the party. Code: `server/src/utils/pricing.js`, `server/src/utils/sasOptionSale.js`.
- `non-card-option-served-persons` — Non-card per-person/per-night options keep the typed number of people (base quantity), red hint when the party changes. Code: `server/src/utils/sasOptionSale.js`, `client/src/pages/ReservationPage.jsx`.
- `breakfast-option-and-planning-card` — The seeded « Petit déjeuner » option with its own planning card, SAS step and `reservations.breakfast*` columns. Code: `server/src/utils/breakfastSeed.js`, `server/src/models/breakfastModel.js`, `client/src/components/OptionDayCard.jsx`.
- `breakfast-option-planning-card` — Breakfast gains per-day occurrence selection (1×/jour) instead of every served morning; amends the card above. Code: `server/src/models/breakfastModel.js`, `server/src/models/planningOptionCardsModel.js`.
- `breakfast-time` — Breakfast time: default on the option, per-reservation override, shown and sorted on the Planning. Code: `server/src/models/breakfastModel.js`, `client/src/components/BreakfastPrepDialog.jsx`.
- `breakfast-offer-price-server-side` — The SAS breakfast offer price/total is computed by the server, not React. Code: `server/src/utils/sasOptionSale.js`, `server/src/plugins/sas/controller.js`.
- `extinguisher-seal-and-repair-amounts` — SAS extinguisher « bon état » check at arrival/departure, billable replacement, configurable repair amounts. Code: `server/src/models/repairAmountsModel.js`, `server/src/plugins/sas/billablesController.js`.
