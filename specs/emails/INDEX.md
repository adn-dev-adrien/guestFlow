# Emails — templates, guest sequence, sending policy, history, language

Start with: `email-automation` (template engine, send modes, pending queue, history). See also: `payments/`, `settings/`, `reservations/`, `sas/`.

- `email-automation` — templates table, `{{tokens}}` and one-level `{{#if}}`, daily 08:00 pass for `auto` templates, « Emails à envoyer » queue, manual send dialog, French failure reasons, length caps. Code: `server/src/controllers/emailsController.js`, `server/src/utils/emailTemplateRenderer.js`, `server/src/utils/emailContextBuilder.js`.
- `no-automatic-email-without-approval` — nothing mails a guest without the operator: only an enabled `auto` template leaves by itself, payment requests never, two named exceptions; master switch is history. Code: `server/src/utils/autoSendPolicy.js`, `server/src/utils/emailAutoSendScheduler.js`.
- `guest-email-sequence` — the six sequence mails (confirmation, J-7, J-2, J+1, November, January): eligibility, one-send ledger, yearly cap, per-template auto mode, simulation tab and CLI. Code: `server/src/utils/guestEmailSequence.js`, `server/src/utils/guestEmailSequenceRunner.js`.
- `guest-email-texts-made-simple` — « Textes des emails » page in send order: live preview, variables on demand, one language at a time, arrival facts, CSV, HTML + text mails. Code: `client/src/pages/settings/EmailTextsSettingsPage.jsx`, `server/src/utils/emailDraftPreview.js`, `server/src/utils/guestEmailHtml.js`.
- `email-language-fr-en` — bilingual templates, English context and amounts, no English version means no mail to an English-speaking guest. Code: `server/src/utils/emailTemplateLanguage.js`, `server/src/utils/emailMoney.js`.
- `email-client-language-and-fiche-polish` — email language lives on the client (reservation value as fallback); option and resource names in the guest's language. Code: `server/src/utils/emailContextBuilder.js`, `client/src/components/ClientFormFields.jsx`.
- `email-history-rolling-window` — history lists only stays within arrival + 3 days (or send + 3 days), older rows purged daily; Paris time; cards below `md`. Code: `server/src/models/emailLogModel.js`, `client/src/pages/EmailHistoryPage.jsx`.
- `manual-email-from-template` — « Créer un email »: queue any template for any reservation on demand, already-sent guard, « Ajouté manuellement ». Code: `client/src/components/EmailComposeDialog.jsx`, `server/src/models/emailLogModel.js`.
- `mark-email-sent-manually` — « Marquer comme envoyé » on a pending row logs a `manual` send without contacting the guest. Code: `server/src/controllers/emailsController.js`, `client/src/components/EmailPendingList.jsx`.
- `j1-arrival-reminder-email` — J-2 reminder mechanics (`arrival_reminder_1d`): resources list, caution-not-received, cleaning and nordic-bath flags, force-sync migration; shipped copy replaced. Code: `server/src/utils/emailContextBuilder.js`, `server/src/utils/migrateArrivalReminderJ2.js`.
- `j1-linen-default-message` — `bedLinenProvidedByDefault` / `bedLinenBringYourOwn` flags and `reservedOptionsList` for linen-by-default properties. Code: `server/src/utils/emailContextBuilder.js`.
- `j7-email-baby-beds` — server-computed `babyBedNotice` sentence and `hasBabyBedNotice` flag from `babies` and `babyBeds`. Code: `server/src/utils/emailContextBuilder.js`, `server/src/utils/templateTokens.js`.
- `j2-email-coffee-and-sas-complement` — `complementNotice` as the SAS-style itemised list with Total, sale-detail source, « à votre départ » when deferred. Code: `server/src/utils/emailContextBuilder.js`, `server/src/utils/reservationEmailGraph.js`.
