# Site — the public website: `/public/v1` API, WordPress plugin and booking drawer, online payment, site content, analytics

Start with: `public-api` (the contract every site flow consumes, rules and endpoints). See also: `plugins/`, `payments/`, `gift-vouchers/`, `options/`.

- `public-api` — read-only catalogue, quote and booking-request endpoints under `/public/v1`, API-key auth, devis created as `requestOrigin='public'`, bilingual refusals, stay-rule checks. Code: `server/src/plugins/website-booking/routes/index.js`, `server/src/plugins/website-booking/publicProjections.js`.
- `wordpress-plugin` — GuestFlow Booking plugin: server-side proxy, cache, blocks (calendar, booking, properties, vouchers, session), settings page, proof-of-work, no price logic in PHP/JS. Code: `integrations/wordpress/guestflow-booking/guestflow-booking.php`, `integrations/wordpress/guestflow-booking/includes/class-gf-rest-proxy.php`.
- `wordpress-plugin-self-update` — the plugin updates itself natively from GuestFlow's releases through the WordPress updater. Code: `integrations/wordpress/guestflow-booking/includes/class-gf-updater.php`, `server/src/plugins/website-booking/controllers/pluginUpdateController.js`.
- `wp-booking-widget-redesign` — unified booking widget: calendar-driven dates, steppers, resources, sticky bar, field-by-field refusals. Code: `integrations/wordpress/guestflow-booking/blocks/booking/view.js`.
- `site-booking-drawer` — the Solio two-screen booking funnel (drawer) wrapped around the widget; screens, bar, confirmation. Code: `integrations/wordpress/guestflow-booking/blocks/booking/view.js`.
- `booking-drawer-friction` — amends the drawer: no friction on the récapitulatif, « Suivant » in the bar, second action, inert hidden screen. Code: `integrations/wordpress/guestflow-booking/blocks/booking/view.js`.
- `site-english-version` — English site: language resolved per request, `lang` carried on every API call, bilingual errors and confirmations, `.po/.mo` strings. Code: `integrations/wordpress/guestflow-booking/includes/class-gf-language.php`, `server/src/plugins/website-booking/publicInputValidation.js`.
- `translation-catalogue` — English texts of options, resources and categories collected by GuestFlow, exported and imported as CSV, flagged when French changes. Code: `server/src/controllers/translationsController.js`, `server/src/utils/translationCollector.js`.
- `public-online-payment` — full online payment of a website devis through a Qonto link: capability token, exactly-once confirmation, webhook plus poll, conflict handling. Code: `server/src/controllers/public/publicPaymentController.js`, `server/src/plugins/online-payment/webhookController.js`.
- `public-online-deposit` — per-property « Acompte en ligne » mode: server decides deposit vs full, deposit link, balance request by manual button only. Code: `server/src/utils/paymentRequestService.js`, `server/src/controllers/public/publicPaymentController.js`.
- `public-planning-options` — planning-card options in the public flow billed by quantity, unscheduled, with server-owned labels and the « à planifier » notice. Code: `server/src/plugins/website-booking/publicProjections.js`, `server/src/utils/pricing.js`.
- `site-meal-portions` — per-person card options counted in portions with a cap of persons × servings, clamped in the quote and refused in requests. Code: `server/src/utils/pricing.js`, `server/src/plugins/website-booking/publicProjections.js`.
- `site-extra-guest-line` — the quote shows the extra-guest supplement as its own line and keeps the guest cap closed server-side. Code: `server/src/plugins/website-booking/publicProjections.js`, `server/src/plugins/website-booking/controllers/publicQuoteController.js`.
- `site-booking-notifications` — website devis keep full options and resources, dashboard alert for pending public devis, operator e-mail and push per request. Code: `server/src/utils/notificationService.js`, `server/src/plugins/website-booking/controllers/publicBookingRequestController.js`.
- `public-request-abuse-and-grouping` — bot-proof requests without a global lockout (challenge, per-visitor limits, purge) and one quote per stay. Code: `server/src/plugins/website-booking/challenge.js`, `server/src/plugins/website-booking/requestStore.js`, `server/src/plugins/website-booking/requestPurge.js`.
- `site-outside-resource-booking` — « Réserver une séance » page: book an hourly resource outside a stay, paid online or with a gift voucher (recap before a slot, voucher prefills the form), shared `online-sales` push channel. Code: `server/src/plugins/hourly-resources/publicSessionService.js`, `integrations/wordpress/guestflow-booking/blocks/session-booking`.
- `site-traffic-analytics` — Umami traffic stats plus booking attribution (referrer, utm, channel) stored on devis and reservations, shown by channel in finance. Code: `server/src/utils/attributionChannel.js`, `integrations/wordpress/guestflow-booking/assets/attribution.js`.
- `google-vacation-rentals-feed` — plugin pushing prices and availability to Google Vacation Rentals (ARI feed, itineraries, accuracy check). Code: `server/src/plugins/google-vacation-rentals/index.js`, `server/src/plugins/google-vacation-rentals/ariXml.js`.
- `site-lodging-fact-zones` — lodging pages: each fact lives in one zone (page content, WordPress mu-plugins in the site's private repository). Code: none in this repository.
- `site-say-it-once` — removal of duplicated blocks on the live site (à-la-carte section, geo shortcode, FAQ entry), prices only in the drawer. Code: none in this repository.
- `site-season-and-google-rating` — the Estiva's season and the Google rating each written once on the site. Code: none in this repository.
