# Settings — Paramètres pages (Établissement, Plateformes, E-mails, Paiements/Qonto, Google Calendar) and their input rules

Start with: `settings-rationalization` (current menu, pages and per-setting placement). See also: `platforms/` (platform settings), `payments/`, `plugins/`, `emails/`, `accounting/`.

- `settings-rationalization` — current Paramètres: summary home page, four-group shortcut menu, Établissement, Plateformes, TVA & exercice, dead settings removed, derived e-mail, per-reservation unlock. Code: `client/src/constants/settingsMenu.js`, `client/src/pages/settings/SettingsHomePage.jsx`, `server/src/controllers/settingsController.js`.
- `settings` — original settings API: `app_settings` singleton, per-group dirty save, server validation (SIRET, TVA, IBAN, BIC), logo upload PNG/JPEG; Google rules retired. Code: `server/src/controllers/settingsController.js`, `server/src/utils/settingsValidation.js`, `server/src/middleware/multerLogoUpload.js`.
- `settings-submenu-reorg` — laundry day on the Linge page, merged « Vacances & fermetures » and « Options & ressources » tabs; menu layout superseded by rationalization. Code: `client/src/plugins/linen/LinenStockPage.jsx`, `client/src/pages/OptionsResourcesPage.jsx`.
- `settings-input-guards` — bounded day and percent fields refuse out-of-range input with one French message server-side; pool all year, social links list, grouped account plan. Code: `client/src/components/BoundedNumberField.jsx`, `server/src/utils/inputLimits.js`, `server/src/utils/settingsValidation.js`.
- `google-calendar-oauth-rework` — Google Calendar via OAuth connect, calendar picker, per-reservation events kept in sync by hooks plus 15-minute reconcile. Code: `server/src/plugins/google-calendar/index.js`, `server/src/plugins/google-calendar/sync.js`, `server/src/plugins/google-calendar/oauthClient.js`.
- `qonto-settings-in-app` — set up, diagnose and repair the Qonto connection from GuestFlow, with honest health state and fix hints. Code: `server/src/utils/qonto/qontoSettingsController.js`, `server/src/utils/qonto/qontoHealth.js`, `client/src/plugins/online-payment/QontoConnectionCard.jsx`.
- `settings-one-save-and-automatic-webhook` — one Save per Réglages page; Qonto webhook registered automatically, no secret to invent. Code: `client/src/plugins/online-payment/PaymentsSettingsPage.jsx`, `server/src/utils/qonto/qontoWebhookRegistrar.js`.
